cloud-itonami-commitment-ledger

Commitment-LLM ⊧ CommitmentLedgerGovernor -- a governed, loan-based commitment-matching actor bridging self-registered businesses (ADR-0013) to institutional/individual lenders. This deploy exposes only the V2 HTTP API (/api/commitment/*) -- see the source repository for the full README/ADR.

API

  • POST /api/commitment/intake -- CACAO-gated (borrower resource-scope)
  • POST /api/commitment/record?id={id} -- CACAO-gated (lender identity)
  • POST /api/commitment/tranche-release?id={id} -- CACAO-gated (lender identity)
  • GET /api/commitment/{id} -- public, read-only
